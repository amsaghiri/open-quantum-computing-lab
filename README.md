# Open Quantum Computing Lab (OQCL)

**An independent, project-based undergraduate textbook of quantum computing through reproducible experiments.**

Developed by **Ali M. Saghiri, William Paterson University**.

## What makes OQCL different
OQCL is a textbook-first laboratory: scientific concepts and worked examples come before projects. Students progress through 12 chapters and 24 experiments, beginning on simulators and using real hardware only when pedagogically useful and approved.

## Student flow
Learn → predict → reproduce baseline → measure → controlled extension → analyze → submit reproducibly.

## Independence
OQCL is independently authored and vendor-neutral. qBraid QUEST is acknowledged only as an optional execution pathway where relevant. OQCL does not reproduce QUEST notebooks, prose, figures, or assignment text.
