Guide 3 — Submitting with GitHub

About 20 minutesNo GitHub experience needed

You submit a project by adding one folder to your own copy of the OQCL repository and asking for it to be reviewed. That request is called a Pull Request. This guide shows the whole path in the browser, with a command-line option at the end.

Before you start. For graded or QPU work, apply by email first and wait for approval: saghiria@wpunj.edu with the project ID, project title, your name, and a short plan.

Step 1 — Create a GitHub account

If you do not have one, sign up at github.com. Your username becomes part of your project folder name.

Step 2 — Fork the repository

Open the OQCL repository and click Fork in the top-right corner, then Create fork. You now have your own copy at github.com/YOUR-USERNAME/open-quantum-computing-lab. You can change it freely without affecting anyone else.

Step 3 — Prepare your project folder on your computer

Name it with the project ID and your GitHub username, and use this layout:

q01-yourgithubname/
  README.md
  notebook.ipynb
  src/                 # optional
  results/raw/
  results/figures/
  environment/requirements.txt
  REPORT.md
FilePurpose
README.mdQuestion, hypothesis, reproduction instructions, runtime/backend.
notebook.ipynbExecutable experiment and analysis.
results/raw/Machine-readable counts/data; never credentials.
results/figures/Labeled plots/diagrams generated from results.
REPORT.mdBaseline, extension, interpretation, uncertainty, limitations, conclusion.

Step 4 — Upload the folder to your fork

  1. In your fork, open the projects folder.
  2. Click Add file → Upload files.
  3. Drag your whole q01-yourgithubname folder into the page. Dragging the folder keeps its structure.
  4. Under Commit changes, write a short message such as Q01 submission: yourgithubname.
  5. Choose Create a new branch for this commit and click Propose changes.

Step 5 — Open the Pull Request

  1. GitHub shows a page titled Open a pull request. Check that the base repository is amsaghiri/open-quantum-computing-lab.
  2. The description box is pre-filled with the OQCL submission form. Fill in every line: project ID, baseline, extension, result with the metric, and the execution metadata (backend, shots, working time, and cost or credits if any).
  3. Tick each box in the checklist only if it is true.
  4. Click Create pull request.

Step 6 — Respond to review

Your instructor may ask for changes. Edit or upload files on the same branch in your fork and the Pull Request updates automatically. You do not need to open a new one.

Never upload these

API keys, tokens, passwords, private keys, billing or account identifiers, or private student information. Check your notebook outputs too: a token printed in a cell is still a leaked token.

Command-line option

If you already use Git, this does the same as Steps 4 and 5. Replace YOUR-USERNAME and the folder name.

git clone https://github.com/YOUR-USERNAME/open-quantum-computing-lab.git
cd open-quantum-computing-lab
git checkout -b q01-yourgithubname

# copy your finished folder into projects/
cp -r /path/to/q01-yourgithubname projects/

git add projects/q01-yourgithubname
git commit -m "Q01 submission: yourgithubname"
git push -u origin q01-yourgithubname

Then open your fork on GitHub and click Compare & pull request.

Course submission and public publication are separate

Submitting for the course does not publish your work in the public book. Student work enters the curated public book only through an explicit opt-in and attribution process.
