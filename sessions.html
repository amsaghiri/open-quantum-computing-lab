Quantum in 7 Sessions

A guided path through OQCL for students who want a clear order to follow. Each session has one main idea, a short reading, a small experiment you can run, self-check questions, and a project.

How to use it. Do the sessions in order, one per week or at your own pace. Each takes roughly one study sitting for the reading and experiment, plus the time of the project you choose. You need Python with Qiskit installed; Guide 1 shows the setup. All code on these pages was run with Qiskit 2.6 and Qiskit Aer 0.18.

What these sessions are, and are not

They are a study order and a set of small experiments built on the OQCL textbook. They do not replace the chapters, which carry the full explanations and worked examples, and seven sessions will not make anyone an expert. The aim is that after Session 7 you can read a simple circuit, predict what it does, test the prediction, and report the result honestly.
