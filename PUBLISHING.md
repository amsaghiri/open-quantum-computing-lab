# Publish OQCL on GitHub Pages

Repository:
`https://github.com/amsaghiri/open-quantum-computing-lab`

## Upload
1. Create a PUBLIC repository named `open-quantum-computing-lab` under `amsaghiri`.
2. Upload all files and folders from this package to the repository root.
3. Confirm that `index.html` is visible at the repository root.
4. Commit the files to `main`.

## Enable GitHub Pages
1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Branch: **main**.
5. Folder: **/(root)**.
6. Click **Save**.

Expected project-site address:
`https://amsaghiri.github.io/open-quantum-computing-lab/`
