Student submission workflow

  1. Read the prerequisite chapter.
  2. Choose an unclaimed project.
  3. Open a Project Claim Issue.
  4. Wait for approval before any paid/limited QPU run.
  5. Create your project folder and write your hypothesis.
  6. Complete simulator baseline.
  7. Add one controlled extension.
  8. Save raw results, figures, dependencies, and report.
  9. Open a Pull Request.
  10. Revise after review.

Folder contract

projects/Qxx-githubusername/
  README.md
  notebook.ipynb
  src/                 # optional
  results/raw/
  results/figures/
  environment/requirements.txt
  REPORT.md

Security

Never commit API keys, tokens, passwords, private keys, billing/account identifiers, or private student information.

Public-book contributions

Course submission and public publication are separate. Student work should enter the curated public book only through an explicit opt-in/attribution process.
