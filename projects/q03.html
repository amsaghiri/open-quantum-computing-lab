Q03 — X, H, and Interference

Micro25–40 minSimulator

Scientific objective: Verify basic gates and demonstrate H²=I.

Prerequisite reading: Chapter 2 — Qubits, Measurement, and Single-Qubit Gates.

Before you code

  1. Write the state, operation, Hamiltonian, or protocol quantity relevant to this experiment.
  2. Write a qualitative prediction.
  3. Define the metric you will use to decide whether the prediction was supported.

Baseline experiment

Test X|0⟩, H|0⟩, and H(H|0⟩). Predict each result algebraically before simulation.

Step-by-step workflow

  1. Create projects/q03-yourgithubname/.
  2. Write the hypothesis in README.md before running.
  3. Implement the smallest baseline in notebook.ipynb.
  4. Run the simulator baseline and save raw counts/data.
  5. Calculate the required metric numerically; do not rely only on visual inspection.
  6. Create at least one labeled figure or table.
  7. Change exactly one primary experimental variable for the extension.
  8. Repeat the measurement with all other controls fixed.
  9. Explain agreement, disagreement, uncertainty, and limitations in REPORT.md.

Time and execution estimate

Student work: 25–40 min. Execution: Simulator. Simulator runtime is normally a small fraction of student working time for these teaching-scale examples. QPU queue and cost are provider-dependent and must be recorded rather than guessed.

Research extension

Propose one controlled extension that changes a scientifically meaningful variable. State the prediction before execution. A failed prediction is acceptable when the experiment is reproducible and the analysis is sound.

Submission

Claim the project through a GitHub Issue before beginning graded work. Submit the completed folder through a Pull Request and complete the repository checklist.
