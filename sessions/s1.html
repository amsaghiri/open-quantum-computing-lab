Session 1 — Qubits and amplitudes

Session 1 of 7Simulator only

By the end of this session you can describe a qubit with two amplitudes, turn amplitudes into measurement probabilities, and say why phase matters even when you cannot see it in one measurement.

1. Read

  • Chapter 1 — Mathematical Language of Quantum Computing

Read the chapter first. The summary below is a reminder, not a replacement.

2. Key ideas

  • A qubit state is written |ψ⟩ = α|0⟩ + β|1⟩. The numbers α and β are complex amplitudes.
  • The Born rule turns amplitudes into probabilities: P(0) = |α|² and P(1) = |β|². A valid state has |α|² + |β|² = 1.
  • Multiplying the whole state by a global phase changes nothing you can observe. A relative phase between α and β is different: it can change what later gates do.
  • Two states can give identical probabilities when measured right away and still be different states.

3. Try it

Build two states that have the same measurement probabilities but a different relative phase, and check how similar they really are. Write down what you expect before you run the code.

import numpy as np
from qiskit.quantum_info import Statevector

# A qubit state is two complex amplitudes: alpha for |0> and beta for |1>
psi = Statevector([1, 1j]) / np.sqrt(2)

print("valid state:", psi.is_valid())          # is it normalized?
print("probabilities:", psi.probabilities())   # [P(0), P(1)]

# The same probabilities, a different relative phase
phi = Statevector([1, -1j]) / np.sqrt(2)
print("probabilities:", phi.probabilities())
print("overlap |<phi|psi>|^2:", abs(phi.inner(psi)) ** 2)

Output (counts will vary slightly from run to run):

valid state: True
probabilities: [0.5 0.5]
probabilities: [0.5 0.5]
overlap |<phi|psi>|^2: 0.0

What to notice

Both states give 50/50, so a single measurement in the computational basis cannot tell them apart. Yet their overlap is 0: they are orthogonal, as different as two quantum states can be. The difference lives entirely in the relative phase.

4. Check yourself

  1. Why can α = 1 and β = 1 not describe a qubit without rescaling?
  2. What information do you lose if you replace amplitudes by probabilities too early?
  3. Change the second state to [1, 1j] multiplied by −1. Predict the overlap with the first state before you run it.
