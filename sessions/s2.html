Session 2 — Measurement, gates, and interference

Session 2 of 7Simulator only

By the end of this session you can predict the result of the X, Z, and H gates on a single qubit, explain measurement as sampling, and show interference with a three-gate circuit.

1. Read

  • Chapter 2 — Qubits, Measurement, and Single-Qubit Gates

Read the chapter first. The summary below is a reminder, not a replacement.

2. Key ideas

  • A gate is a reversible (unitary) operation on the state. X swaps |0⟩ and |1⟩. Z flips the sign of the |1⟩ amplitude. H turns |0⟩ into an equal superposition.
  • Measurement is sampling: each shot gives 0 or 1, and you estimate probabilities from many shots. More shots give a better estimate, not a different state.
  • Applying H twice returns the qubit to |0⟩. The two paths to |1⟩ have opposite signs and cancel. That cancellation is interference.
  • A Z gate between the two H gates changes only a phase, yet it flips the final answer from 0 to 1. Phase is invisible until interference makes it visible.

3. Try it

Run three small circuits and compare them. Predict each result before you look. Write down what you expect before you run the code.

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

sim = AerSimulator(seed_simulator=7)

def run(build, label):
    qc = QuantumCircuit(1, 1)
    build(qc)
    qc.measure(0, 0)
    print(label, sim.run(qc, shots=1000).result().get_counts())

run(lambda qc: qc.h(0), "H        ")                          # about half 0, half 1
run(lambda qc: (qc.h(0), qc.h(0)), "H, H     ")              # always 0
run(lambda qc: (qc.h(0), qc.z(0), qc.h(0)), "H, Z, H  ")     # always 1

Output (counts will vary slightly from run to run):

H         {'1': 486, '0': 514}
H, H      {'0': 1000}
H, Z, H   {'1': 1000}

What to notice

One H gives a random-looking result. Two H gates give 0 every time, so the randomness was not noise: it was a superposition that could be undone. Inserting Z, which changes no probability on its own, turns the answer into 1 every time.

4. Check yourself

  1. If H made the qubit “randomly 0 or 1”, what would H followed by H give? Why is that not what happens?
  2. What does X do between the two H gates instead of Z? Predict, then test.
  3. How many shots do you need before P(0) for a single H is reliably within 0.05 of 0.5?
