Session 6 — Near-term methods: Hamiltonians and variational circuits

Session 6 of 7Simulator only

By the end of this session you can say what an expectation value is, describe the hybrid loop used by VQE and QAOA, and explain why a classical baseline is always required.

  • Chapter 8 — Hamiltonians, Dynamics, and Trotterization

2. Key ideas

  • A Hamiltonian describes the energy of a system. Measuring an operator many times gives its expectation value, the average result.
  • A parameterized circuit has gates with adjustable angles. Different angles prepare different trial states.
  • The hybrid loop: the quantum circuit prepares a trial state and estimates the energy; a classical optimizer chooses the next angles. VQE, QAOA, and variational classifiers all follow this pattern.
  • At teaching sizes a classical computer solves these problems easily. A small demonstration is never evidence of quantum advantage, so always compare with an exact or classical answer.

3. Try it

A one-qubit version of the variational idea: find the angle θ that minimizes the expectation value of Z for the state Ry(θ)|0⟩. Write down what you expect before you run the code.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, SparsePauliOp

Z = SparsePauliOp("Z")

def energy(theta):
    qc = QuantumCircuit(1)
    qc.ry(theta, 0)                                   # the trial state
    return Statevector(qc).expectation_value(Z).real  # <Z> = cos(theta)

# The "classical optimizer": try many angles and keep the best one
thetas = np.linspace(0, 2 * np.pi, 41)
values = [energy(t) for t in thetas]
best = int(np.argmin(values))

print("lowest <Z> found:", round(values[best], 3))
print("at theta =", round(thetas[best], 3), "(pi =", round(np.pi, 3), ")")

Output (counts will vary slightly from run to run):

lowest <Z> found: -1.0
at theta = 3.142 (pi = 3.142 )

What to notice

The lowest value is −1 at θ = π, where Ry(θ) has rotated |0⟩ into |1⟩. For this state ⟨Z⟩ = cos θ, so you can check the answer by hand. That hand calculation is the classical baseline; in a real problem you would compare against exact diagonalization or brute force.
