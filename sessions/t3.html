Teacher notes — Session 3: Entanglement

For instructorsFlipped format

The session in one sentence. Entangled qubits have joint results that cannot be explained by giving each qubit its own state.

The student page for Session 3 is written for self-study: students can read, work the example, run both experiments, and check their own answers without you. These notes are for the class time you do have.

Before class (students, on their own)

  • Read Chapter 3.
  • Do the worked example and the first experiment on the student page.
  • Bring one written prediction and one question.

If you have 20 minutes

MinutesWhat to do
0–3Ask the exit question below cold, and take a show of hands. Do not give the answer yet.
3–10Board: the worked example from the student page, with students supplying each step.
10–16Live demo: run the second experiment. Collect predictions first, then run it.
16–20Return to the exit question, settle it, and assign the project.

MinutesActivity

Three points to make

  1. Four basis states for two qubits; 2ⁿ in general.
  2. Build the Bell state on the board in three lines.
  3. Correlation alone is not entanglement: show the X-basis measurement.

Board example

Build the Bell state step by step, writing states as |first qubit, second qubit⟩.

  1. Start: |00⟩.
  2. H on the first qubit: (|00⟩ + |10⟩)/√2.
  3. CNOT with the first qubit as control flips the second qubit only in the |10⟩ term: (|00⟩ + |11⟩)/√2.

Why it is not two separate qubits. A product state looks like (a|0⟩ + b|1⟩)(c|0⟩ + d|1⟩) = ac|00⟩ + ad|01⟩ + bc|10⟩ + bd|11⟩. To match the Bell state we need ad = 0 and bc = 0, but also ac ≠ 0 and bd ≠ 0. If ad = 0 then a = 0 or d = 0, which makes ac or bd zero. No choice works, so the state cannot be split.

Misconceptions to raise

  • Saying “the qubits are both 0 or both 1, we just do not know which”. That describes a classical shared coin, not a Bell state.
  • Believing that measuring one qubit sends a signal to the other. The correlations cannot be used to communicate.
  • Reading Qiskit bit strings left to right. Qiskit prints qubit 0 on the right.

Discussion prompts

  • Why can entanglement not be used to send a message faster than light?
  • What does it mean physically that the Bell state cannot be factored?

Exit question

Ask: A Bell pair and a pair of glued classical coins both give only 00 and 11. How do you tell them apart?

Looking for: Measure both in a second basis (H before measurement). The Bell state stays perfectly correlated; the classical pair does not.
