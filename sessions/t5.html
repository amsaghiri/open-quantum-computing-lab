Teacher notes — Session 5: Algorithms: search and phase estimation

For instructorsFlipped format

The session in one sentence. Grover marks the answer with a sign and then uses interference to turn that sign into a high probability.

The student page for Session 5 is written for self-study: students can read, work the example, run both experiments, and check their own answers without you. These notes are for the class time you do have.

Before class (students, on their own)

  • Read Chapter 5 and Chapter 6.
  • Do the worked example and the first experiment on the student page.
  • Bring one written prediction and one question.

If you have 20 minutes

MinutesWhat to do
0–3Ask the exit question below cold, and take a show of hands. Do not give the answer yet.
3–10Board: the worked example from the student page, with students supplying each step.
10–16Live demo: run the second experiment. Collect predictions first, then run it.
16–20Return to the exit question, settle it, and assign the project.

MinutesActivity

Three points to make

  1. Oracle flips a sign: nothing visible yet.
  2. Diffusion as “reflect about the average”, worked on the board for four states.
  3. One round too many spoils it: run the second experiment live.

Board example

Grover on four states, by hand. Suppose the marked state is |11⟩.

  1. After the first H gates, all four amplitudes are ½.
  2. Oracle: the marked amplitude becomes −½. The amplitudes are (½, ½, ½, −½).
  3. Average: (½ + ½ + ½ − ½)/4 = ¼.
  4. Diffusion replaces each amplitude a by 2 × average − a. Unmarked: 2 × ¼ − ½ = 0. Marked: 2 × ¼ − (−½) = 1.

The final amplitudes are (0, 0, 0, 1), so the marked state is measured with certainty after one round.

Misconceptions to raise

  • Saying Grover “tries all answers at once”. It rotates amplitude toward the answer step by step.
  • Running more rounds to be safe. Too many rounds rotate the state past the answer and the success probability falls.
  • Forgetting that the oracle changes only a sign. On its own it changes no probability.

Discussion prompts

  • Where exactly does the speed-up come from, if the oracle is called one item at a time?
  • Why is a quadratic speed-up for unstructured search less dramatic than it sounds for real databases?

Exit question

Ask: After the oracle, what is the probability of measuring the marked state among four?

Looking for: Still ¼. The oracle changes only the sign of the amplitude.

One project from this session, following the predict → baseline → one extension → analyze routine. Project solutions are deliberately not published on this site.
