Teacher notes — Session 1: Qubits and amplitudes

For instructorsFlipped format

The session in one sentence. A qubit is described by two complex amplitudes, and probabilities come from their squared magnitudes.

The student page for Session 1 is written for self-study: students can read, work the example, run both experiments, and check their own answers without you. These notes are for the class time you do have.

Before class (students, on their own)

  • Read Chapter 1.
  • Do the worked example and the first experiment on the student page.
  • Bring one written prediction and one question.

If you have 20 minutes

MinutesWhat to do
0–3Ask the exit question below cold, and take a show of hands. Do not give the answer yet.
3–10Board: the worked example from the student page, with students supplying each step.
10–16Live demo: run the second experiment. Collect predictions first, then run it.
16–20Return to the exit question, settle it, and assign the project.

Three points to make

  1. A bit has a value. A qubit has two amplitudes, and we only ever see samples.
  2. Born rule on the board with one numeric example.
  3. Same probabilities does not mean same state: show the two states from the Try-it code.

Board example

Normalize 3|0⟩ + 4i|1⟩ and find the probabilities.

  1. Squared length: |3|² + |4i|² = 9 + 16 = 25, so the length is 5.
  2. Divide by the length: |ψ⟩ = (3/5)|0⟩ + (4i/5)|1⟩.
  3. Born rule: P(0) = (3/5)² = 0.36 and P(1) = |4i/5|² = 0.64.
  4. Check: 0.36 + 0.64 = 1.

The factor i did not affect either probability. It is a relative phase, and it will matter as soon as another gate is applied.

Misconceptions to raise

  • Adding amplitudes and expecting 1. It is the squared magnitudes that add to 1.
  • Squaring a complex amplitude instead of taking its magnitude first: |i|² = 1, but i² = −1.
  • Deciding that phase is irrelevant because it does not show up in one measurement.

Discussion prompts

  • If we can only observe probabilities, in what sense is the phase “real”?
  • What would go wrong if we described a qubit by P(0) and P(1) alone?

Exit question

Ask: Two states both give 50/50 when measured. Are they necessarily the same state?

Looking for: No. They can differ in relative phase, and can even be orthogonal, as (|0⟩+i|1⟩)/√2 and (|0⟩−i|1⟩)/√2 are.
