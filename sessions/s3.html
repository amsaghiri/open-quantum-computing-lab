Session 3 — Entanglement

Session 3 of 7Simulator only

By the end of this session you can write a two-qubit state in the computational basis, build a Bell state with H and CNOT, and say what the measurement results do and do not show.

1. Read

  • Chapter 3 — Multiple Qubits, Tensor Products, and Entanglement

Read the chapter first. The summary below is a reminder, not a replacement.

2. Key ideas

  • Two qubits have four basis states: |00⟩, |01⟩, |10⟩, |11⟩. In general n qubits need 2ⁿ amplitudes.
  • A CNOT flips the target qubit only when the control qubit is 1.
  • H on the first qubit followed by CNOT produces the Bell state (|00⟩ + |11⟩)/√2. It cannot be written as “a state of qubit A” times “a state of qubit B”. That is entanglement.
  • Each qubit alone looks random, but the two results always agree. Agreement in one basis is not yet proof of entanglement; you need a second measurement basis to rule out an ordinary shared coin.

3. Try it

Build the Bell state and look at which outcomes appear. Write down what you expect before you run the code.

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

qc = QuantumCircuit(2, 2)
qc.h(0)          # put qubit 0 in superposition
qc.cx(0, 1)      # entangle qubit 1 with qubit 0
qc.measure([0, 1], [0, 1])

counts = AerSimulator(seed_simulator=7).run(qc, shots=1000).result().get_counts()
print(counts)    # only '00' and '11' appear

Output (counts will vary slightly from run to run):

{'11': 511, '00': 489}

What to notice

Only 00 and 11 appear, each about half the time; 01 and 10 never do. Each qubit on its own is 50/50, but together they are perfectly correlated. Note that Qiskit prints the bit string with qubit 0 on the right.

4. Check yourself

  1. A classical pair of coins glued together also gives only 00 and 11. What extra measurement separates that from a Bell state?
  2. Add a third qubit and one more CNOT to make a GHZ state. Which outcomes do you expect?
  3. How many amplitudes describe 10 qubits? 30 qubits?
