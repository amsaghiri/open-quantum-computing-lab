# Qxx — Project title: Report

## 1. Baseline
What did you reproduce? State the prediction you wrote before running, then the measured result (give the metric as a number, not only a figure).

## 2. Extension
Which single primary variable did you change? What stayed fixed? What did you predict?

## 3. Results
Tables and labeled figures (stored in `results/figures/`). Report the metric for the baseline and for the extension.

## 4. Interpretation
Did the results support the prediction? Separate three possible sources of any difference:
1. the ideal mathematical prediction,
2. finite-shot sampling,
3. implementation effects such as noise or compilation.

## 5. Uncertainty
How large is the sampling uncertainty? How do you know (repeated runs, shot count, error estimate)?

## 6. Limitations
What can this experiment NOT tell us? What would you change with more time or resources?

## 7. Conclusion
Two or three sentences: what you learned and what evidence supports it.

## Sources
List every third-party source, tutorial, or code you used.
