QUEST Laboratory Path

Choose a suitable simulator or quantum platform for each activity; QUEST is one optional resource.

Student direction: Review the projects below and claim one before beginning substantial work. Complete prerequisite reading, prediction, simulator baseline, and resource estimate before approved QPU use.

1. Learn before you execute

Read the prerequisite OQCL chapter, work through the mathematics and example, and write a falsifiable prediction. Understand the experiment before opening a hardware platform.

3. Simulator baseline

Implement and debug the smallest correct baseline on a simulator. Preserve raw counts/data and calculate the project metric. A screenshot is not a substitute for data.

4. Plan hardware use

  • Identify an approved backend/device.
  • Estimate circuits/jobs and shots.
  • Estimate credits/cost when applicable.
  • Preserve the logical circuit.
  • Obtain instructor approval when required.

5. Continue on official QUEST/qBraid

For account access, current devices, navigation, job submission, credits, and platform-specific procedures, follow the current official source. OQCL intentionally does not duplicate changing platform instructions.

Open Official QUEST →

6. Bring the experiment back to OQCL

Record backend/device, date/time, shots, jobs, logical and transpiled circuits, depth, two-qubit gate count when relevant, raw counts/data, job metadata, and credits/cost when available.

8. Extend and submit

Change one scientifically justified variable, repeat with controls fixed, interpret the result, and submit notebook, raw data, figures, metadata, and report through the OQCL GitHub workflow.

Attribution: QUEST/qBraid is an external laboratory resource. OQCL is independent. Platform instructions and current service details remain with the official source; OQCL teaching, project questions, analysis workflow, and submission requirements are independently authored.

How to Apply for a Project

Choose a project and email saghiria@wpunj.edu with the project ID and project title, your name, and a short description of your planned experiment. Wait for instructor approval before starting graded or QPU work.

Supplementary resource: qBraid QUEST. Use the related course activity when available; OQCL provides the learning objectives and analysis requirements.
